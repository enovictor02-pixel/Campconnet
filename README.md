
# CampConnect

### A Digital Support Platform for NYSC Corps Members
## Live Demo

[View CampConnect Live](https://dynamic-paprenjak-1093b4.netlify.app/)

CampConnect is an early-stage web application prototype designed to help National Youth Service Corps (NYSC) members access useful camp information and support services in one place.

The platform aims to make camp life more organised by bringing announcements, activity schedules, facility information and member support into a single interface.

## Key Features

- **Member Dashboard:** A responsive dashboard for accessing camp information.
- **Announcements:** View camp updates and notifications.
- **Activity Timetable:** Access camp schedules and activities.
- **Facility Directory:** Explore camp facilities through a demonstration map interface.
- **User Authentication:** Sign-up, sign-in and password-reset workflows using Supabase Auth.
- **Member Profiles:** Profile synchronisation with a Supabase database.
- **Support Requests:** Submit support requests through the application.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Supabase Authentication
- Supabase Database

## Current Development Status

CampConnect is an early-stage prototype.

Some features demonstrate working frontend interactions, while others depend on Supabase configuration or use sample data.

### Current Limitations

- The map and facility locations are demonstration interfaces, not live GPS navigation.
- Some announcements and timetable entries use sample data.
- Admin management features are not fully connected to a secure backend.
- Authentication and database workflows require correctly configured Supabase tables and security policies.
- The application has not been presented as a production-ready or security-audited service.

## Future Improvements

- Live GPS location and directions.
- Accommodation discovery and landlord/agent connections.
- Improved administrative dashboard.
- Secure role-based access control.
- Real-time camp announcements.
- Expanded member support services.

## Project Objective

The long-term vision is to create a digital ecosystem that makes information, accommodation discovery and essential support services more accessible to corps members.
